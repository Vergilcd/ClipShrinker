CLIP SHRINKER - CHANGELOG
=========================
Made with Claude (Anthropic) by Vergil. Open source (MIT) - see LICENSE.txt.
Newest version first.


NEW IN 1.0.8
- Faster first start: the check for the NVENC encoder (it starts ffmpeg once) now runs in the background,
  so the window no longer waits for it. On the very first start Windows scans the freshly unpacked files
  (Python, ffmpeg), which could keep the window hidden for several seconds.
- Smoother window resizing: the timelines, the "Drop videos here" box, the "Add videos" strip and the
  progress bar are redrawn at most about 30 times per second while the window is dragged (they were
  redrawn on every single pixel step), and the total length is no longer recalculated for every step.
- Fixed: two harmless "Duplicate element DangerButton.button" errors were written to clipshrinker.log on every
  start (the red "Clear all" button style was created twice).
- clipshrinker.log now also contains timing lines: where the start-up time goes ("[start-up ...]") and a
  summary after each window resize ("[resize] ..."). They are only used to find slow spots.

NEW IN 1.0.7
- The package no longer contains the developer helper Prepare-Portable-Python.bat (it only prepares
  the bundled Python and is not needed to run the program).

NEW IN 1.0.6
- Clicking anywhere outside a text field or drop-down in the sidebar now leaves it: the cursor stops
  blinking, typed values are accepted and a chosen drop-down entry no longer stays highlighted.

NEW IN 1.0.5
- The remark under the Crop setting ("already narrower - no crop") is smaller and always one line, so the
  settings no longer move when it appears. The settings area also avoids repeated re-layouts when its
  scrollbar appears or disappears (a possible cause of a doubled-up drawing seen on one computer).

NEW IN 1.0.4
- The Shortcuts window uses two columns, so it is about half as high (it was cut off on 1080p screens).

NEW IN 1.0.3
- The bundled Python is about 9 MB smaller on disk (about 3 MB smaller download): unused parts removed
  (sqlite3, unittest, turtle, Tix, Tcl time-zone data, Tk demos and the Python self-test files).

NEW IN 0.8.0 - BITRATE PRESETS, EXPORT QUESTION
-----------------------------------------------
  * New "Presets" button (left of Settings): bitrate profiles with a name, a bitrate in Mbps and an
    optional hotkey. They are saved in presets.json next to the program. Edit / X to change or delete a
    profile, "+ Add profile" adds another one.
  * Every clip has a bitrate drop-down in its title bar: Auto (= size / bitrate from Settings) or a preset.
    Press a preset's hotkey to give the preset to the selected clips (or the active clip).
    The per-clip bitrate is used when the clips are exported as separate files. A joined video follows the
    size / bitrate in Settings. The choice is saved in projects and is part of undo / redo.
  * "Each clip as its own file / Join into one video" is no longer a setting: Export asks when there are
    several clips. Transition and length stay in Settings (they only matter when joining).
  * Solid progress bar again (blue, green when finished). "Clear all" is red.
  * Closing the program asks only: Save / Close without saving / Cancel.

NEW IN 0.7.0 - RIFE AI SLOW MOTION, EXPORT POLISH
-------------------------------------------------
  * Slow-motion sections can be smoothed with RIFE (AI frame interpolation, rife-ncnn-vulkan by nihui,
    MIT licence). Settings -> Slow-motion sections -> Smoothing: Repeat frames / Frame blending / RIFE.
    The first time, click "Download RIFE" there (about 30 MB, one time, into library\rife). If the
    download does not work, unzip the Windows release from github.com/nihui/rife-ncnn-vulkan/releases
    into library\rife by hand. It needs a Vulkan-capable graphics card (any recent NVIDIA card is fine).
  * RIFE is applied while exporting (the sections are rendered first: the bar shows
    "Slow motion (RIFE) 1/2 ..."). The preview keeps showing frame blending. If RIFE is missing or fails,
    that section falls back to frame blending, and the reason is written to clipshrinker.log.
  * Temporary frames are stored in the Windows temp folder and removed when the export is done.
    A 0.25x section of a long 4K clip needs a few GB of free space while it runs.
  * "Export..." is now "Export" and Ctrl+E starts it.
  * New striped progress bar. The "Open folder" button now sits to the right of it.
  * The status line starts with a check mark when an export finishes and a cross when it is
    cancelled or fails.

NEW IN 0.5.9 - SLOW-MOTION SECTIONS, VHS SOUND OPTION
-----------------------------------------------------
  * Press D to add a slow-motion section (pink, starts at 0.5x). It works like the blue speed section:
    type any multiplier below 1 in its box (e.g. 0.25) - or type 1 or more and it turns blue.
  * Slow-motion video is smoothed by blending neighbouring frames instead of repeating them
    (Settings -> "Smooth slow-motion"). It is not true interpolation, so very slow sections can look
    a little ghosty. The sound is slowed with the pitch kept.
  * The VHS rewind effect now only applies to speed-UP sections, and the tape sound has its own switch
    (Settings -> "VHS rewind sound effect"). The sound effect is also 25% quieter.

NEW IN 0.5.8 - VHS REWIND EFFECT
--------------------------------
Sped-up sections now get a VHS rewind look and sound, in the preview and in the export:
  * noise, colour bleed and a rolling tracking band while the section runs
  * a stronger glitch burst plus a rising tape-wind whoosh when the section starts, and a
    falling one when it returns to normal speed
  * sections shorter than 0.15 s (after speeding up) get no effect
Turn it on/off in Settings -> "VHS rewind effect on sped-up sections" (on by default, saved in projects).

NEW IN 0.5.7 - TIDIER TOP BAR
No 'Add videos' button: drop videos onto the window or click the drop zone (a slim strip below the clip list
when clips are loaded). 'Clear all' moved under the preview. Undo / redo are icon buttons (Ctrl+Z,
Ctrl+Shift+Z). Shortcuts window split into General / Preview / Timeline. New: M mutes / unmutes the preview.

NEW IN 0.5.6 - UNDO / REDO
Undo / Redo buttons (top bar), Ctrl+Z and Ctrl+Y (or Ctrl+Shift+Z) for: removing, adding and reordering
clips, clear all, opening a project, trim markers, speed sections and their multipliers. Removed clips are
kept hidden (with their thumbnails) so undo brings them back instantly; the last 60 steps are remembered.

NEW IN 0.5.5 - SELECTING CLIPS
Shift+click (on a clip's title line or its strip) selects everything between the active clip and the clicked
one; Ctrl+click adds / removes single clips; Ctrl+A selects all. Selected clips have the blue title bar like
the active one. Delete removes all selected clips (and the active one); if a speed section is selected,
Delete removes just that section. A selected speed section is shown as a light cyan bar.

NEW IN 0.5.4 - PROJECTS
Project button (top left) / Ctrl+O / Ctrl+S / Ctrl+Shift+S: open and save projects (*.clipproj) with the clips
in order, trim markers, speed sections and the export settings. Dropping a project file onto the window opens
it. If a clip moved, the program also looks for it relative to the project file's folder.
Settings -> APP -> 'Restore the last session on start' (off by default) reopens the clips of the last session.

NEW IN 0.5.3 - FASTER THUMBNAILS
Thumbnails of a clip are now made by a single ffmpeg run (one quick seek per thumbnail, key frames only)
instead of one program start per thumbnail. Up to 4 clips are processed in parallel; the active clip first,
then the others in list order. Thumbnails appear one by one as soon as they are ready.

NEW IN 0.5.2
Hotkeys 1 / 2 set the trim start / end marker at the playhead (while playing or scrubbing; the markers can
still be dragged). While playing, a moved end marker takes effect immediately. The '?' button is now
'Shortcuts'.

NEW IN 4.3/4.4 - SMOOTHER PREVIEW (4K CLIPS)
Play from any point starts the picture immediately. Preview audio is now streamed continuously (no
temporary files, no gaps or dropouts) and starts exactly with the first frame. Decoding and downscaling of
the preview run on the GPU when possible (no crop / HDR tone-mapping / speed sections active); the preview
falls back automatically if the GPU path is not available.
Preview timings are written to clipshrinker.log (library folder) - useful if anything still feels slow.
