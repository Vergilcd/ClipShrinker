AI EDITING - CHANGELOG
======================

0.7.1 (Clip Shrinker 2.9.5)
- export no longer replaces an existing file named in "out" unless the call says overwrite: true (Claude is
  told to ask you first). Automatic names were already safe: they get " (2)" and so on.
- Numbers such as "NaN" or "Infinity" are refused instead of being used as a time or a setting.
- A tool that hits an unexpected error reports it instead of stopping the helper (frames with an empty time
  stopped it).
- set_export_settings checks every value before it changes anything; a wrong resolution used to leave the
  prefix and other values already changed.
- Without the open app, prefix, suffix and keep_name are refused with a note: a project file does not keep
  them, so before they were "changed" and then lost.

0.7.0 (Clip Shrinker 2.9.0)
- add_section can add a pause (kind "pause", from = the frame that stays, length = seconds); clear_sections
  can remove only pauses. Clip info lists pauses, and a sound's end time now follows speed sections and pauses.

0.6.0 (Clip Shrinker 2.8.0-beta3)
- New tool "guide": step-by-step guides Claude reads before a bigger job. The first one, "subtitles", is how to
  make an .srt file: short transcribe windows, dropping made-up lines, checking words against the game's
  on-screen subtitles, fixing line starts after pauses, one sentence per subtitle. The helper answers it itself,
  so it also works with an older Clip Shrinker open.

0.5.0 (Clip Shrinker 2.8.0-beta2)
- Speech to text on the graphics card: the module's ffmpeg loads whisper's Vulkan backend (ggml-vulkan.dll) when
  the PC has a Vulkan driver, else the CPU backend; the CPU part picks the best build for the processor
  (ggml-cpu-*.dll). whisper.cpp and ggml are DLLs next to ffmpeg.exe now. Clip Shrinker 2.8.0-beta1 keeps using
  the CPU with this version; 2.8.0-beta2 uses the graphics card.

0.4.0 (Clip Shrinker 2.8.0-dev3, 2.8.0-beta1)
- Downloaded on demand: not part of the Clip Shrinker download any more. Install, Update and Uninstall on this
  card; the parts (helper, speech ffmpeg, speech model) come from the GitHub release "ai-editing" and are
  checked with SHA-256. "Connect to Claude Code" registers the helper.
- Speech to text uses the module's own ffmpeg (modules\ai-agent\ffmpeg); the app's ffmpeg is the base build.

0.3.0 (Clip Shrinker 2.8.0-dev2)
- Off after the first start; switching it on shows a privacy notice (frames, speech, file names and settings
  go to Anthropic) and only goes on after "I understand, switch on".
- New tools: export settings and file names (export_settings, set_export_settings), sounds (sound_library,
  download_sound, add_sound, remove_sounds), speech to text (transcribe, ffmpeg's whisper filter), white balance
  in set_picture.

0.2.0 (Clip Shrinker 2.8.0-dev)
- Development version. With the clipshrinker MCP helper set up in Claude Code, Claude connects to the open
  Clip Shrinker window (the header shows "AI agent connected") and works on the clips on the timeline: it looks
  at frames, finds moments, trims, adds speed / zoom sections, sets the picture and exports when asked. Every
  change shows on the timeline at once and Ctrl+Z undoes it. Without the window open it edits .clipproj files.
